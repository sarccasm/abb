ГОТОВИЙ САЙТ-ПРИВІТАННЯ

1. Відкрий index.html у браузері — сайт уже працює.
2. Щоб вставити фото:
   - візьми потрібну фотографію;
   - назви її photo.jpg;
   - поклади в ту саму папку, де index.html.
3. Текст привітання можна змінити прямо в index.html:
   - головний короткий текст — блок <p class="sub">
   - велике привітання — секція <section class="message">
4. Для публікації можна:
   - закинути папку на Netlify Drop;
   - GitHub Pages;
   - Vercel.

Ефекти:
- падаючі пелюстки;
- анімоване відкриття;
- декоративні георгіни/кущові троянди;
- плавний паралакс фотографії;
- сердечка/іскри при кліках;
- адаптація під телефон.
